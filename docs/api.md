# HTTP API

`/api/v1` is the stable control-plane prefix. Existing fields and routes remain
compatible; new fields have defaults. OpenAPI is generated by FastAPI and a
semantic test freezes methods, parameters, request models and response codes.

User routes cover health, state, capabilities, hardware, datasets, runs,
metrics, logs, exports, sessions, approvals and SSE events. Lists support
bounded `limit`/`offset`; runs also filter by `status`. Error responses use
`error`, `type` and `request_id`. Responses include `X-Request-ID`,
`X-Kernelyra-API-Version`, no-sniff, no-referrer, frame denial, CSP and no-store.

`GET /api/v1/events` is a bounded SSE stream. Reconnect with `Last-Event-ID` or
`after`; a slow client consumes a private bounded page and never blocks training.

MCP-facing HTTP routes live under `/api/v1/mcp`. They require a scoped agent
session and repeat action/path checks inside the daemon. Risky operations consume
a one-time approval. CORS is disabled because this is a headless
service-to-service gateway. Configure approved Host values when embedding it.
